# NOCLIP

A first-person horror roguelite about falling out of reality, built in Godot 4.7 entirely by AI agents, for a first independent Steam release.

- **Design:** `docs/design/00_OVERVIEW.md` is the director's overview; the numbered documents specify each system.
- **Agents:** `CLAUDE.md` is the entry point for any agent working here. Role definitions live in `.claude/agents/`.
- **Plan:** `docs/design/15_production_plan.md` lists milestones, tasks, and model recommendations.
- **Reference:** `third_party/gd-agentic-skills/` is a vendored copy of [gd-agentic-skills](https://github.com/thedivergentai/gd-agentic-skills) (LGPL-3.0, commit in `VENDORED_COMMIT.txt`), used as reference material during development and not shipped with the game.

The Godot project will live in `game/` once production starts.
